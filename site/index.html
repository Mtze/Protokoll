Protokoll

Private meeting notes for your Mac. Hit record, and get a full transcript and clear minutes - all on your own machine.

Install View on GitHub

Install

Protokoll installs with Homebrew on macOS 14+ (Apple Silicon).

brew tap mtze/protokoll https://github.com/Mtze/Protokoll brew install --cask protokoll

Update later with brew upgrade --cask protokoll. Protokoll isn't notarized yet, so if macOS blocks the first launch you can instead run brew install --cask --no-quarantine protokoll.

First launch

A few one-time steps so Protokoll can record and process your meetings:

  • Open the app. If macOS says it can't be opened, go to System Settings → Privacy & Security and choose Open Anyway (or use the --no-quarantine install above).
  • Allow the microphone when asked - this captures your voice.
  • Allow screen recording to also capture the other side of a call (video-call and system audio).
  • Sign in to Claude. Protokoll writes your summaries using your existing claude login - no API key needed.
  • Run Diagnostics. The built-in panel installs the rest for you (ffmpeg and a local Whisper engine) with one click.

How it works

1

Record

Capture your mic and the call audio together, so the whole conversation is covered.

2

Transcribe

Whisper turns the audio into a timestamped transcript, right on your Mac.

3

Summarize

Get tidy minutes - decisions, action items with owners, and open questions.

Your recordings and notes are just files in a folder you own - Protokoll never hides them in a database.

Private by design

  • Transcription runs locally with Whisper - your audio never leaves the Mac.
  • Summaries use your own Claude login, not a shared server or API key.
  • Nothing is uploaded to third parties. Your meetings stay yours.

Requirements

  • macOS 14 or later on Apple Silicon.
  • The claude CLI, signed in (claude login).
  • ffmpeg and a Whisper engine - the app's Diagnostics panel installs these for you.

Troubleshooting

The app won't open ("unidentified developer" / "damaged")

Protokoll isn't notarized yet. Open System Settings → Privacy & Security and click Open Anyway, or reinstall with brew install --cask --no-quarantine protokoll.

No transcript, or "ffmpeg not found"

Open the app's Diagnostics panel and run the checks - it installs ffmpeg and a Whisper engine and fixes the tool path for you. The end-to-end System-Test confirms everything works.

What languages are supported?

The app is localized in English and German, and Whisper transcribes many spoken languages. Pick your transcription language in Settings.

Where are my recordings and notes?

Everything lives as plain files in your Protokoll container folder - audio, the transcript, and the summary. They're the source of truth, so you can read, back up, or move them like any other files.
